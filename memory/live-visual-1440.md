# Живой просмотр fabrika-v6

URL: https://lilkutabare-hue.github.io/fabrika-v6/
Chrome, два вьюпорта. Репозиторий не менялся.

Условия media:

- 1440×900: `(hover: hover)` и `(pointer: fine)`, `prefers-reduced-motion: no-preference`, dpr ≈ 1.
- 1024×1366: `(hover: none)`, `(pointer: coarse)`, тач, dpr ≈ 1.

## 1. «Каталог» (`a.is-catalog.btn`)

Видна на обоих экранах. Прямоугольник. На 1024 это плоский чёрный. На 1440 в computed style есть стекло, на белом герое оно читается как та же чёрная плашка.

1440, computed:

- border-radius: `0px`
- background-color: `rgba(0, 0, 0, 0.8)`
- background-image: `linear-gradient(rgba(255, 255, 255, 0.18), rgba(255, 255, 255, 0) 46%)`
- border: `1.01587px solid rgba(255, 255, 255, 0.48)` (со всех сторон)
- backdrop-filter: `blur(8px) saturate(1.4)`
- box-shadow: `rgba(255, 255, 255, 0.4) 0px 1px 0px 0px inset, rgba(0, 0, 0, 0.5) 0px 8px 18px -12px`
- размер: 90.3×48, padding `0 22px`, font `700 12px/12px Jost`

1024, computed:

- border-radius: `0px`
- background-color: `rgb(0, 0, 0)`
- background-image: `none`
- border: `0`
- backdrop-filter: `none`
- box-shadow: `none`
- размер: 87.4×48, тот же шрифт 12px/700

Базовый `.btn` в `base.css` задаёт `border-radius: 999px`. Инлайн-правило `.btn { border-radius: 0 !important; background: rgb(0,0,0) !important; border: 0 !important; box-shadow: none !important }` его перекрывает. Стекло с 1440 побеждает только заливку, рамку, blur и тень (селектор `a.btn:not(.btn--ghost)` внутри `(hover: hover) and (pointer: fine)`), радиус остаётся 0.

## 2. «Свой принт» и `.hop`

На 1440 буквы есть: 9 спанов `.hop` внутри `.hop-run` («С в о й / п р и н т», `--d` 0…8).

Только у этой ссылки их нет. Всего 128 букв на 10 контролах:

| Хост | Букв |
| --- | --- |
| Свой принт | 9 |
| FABRIKA.MARKET | 14 |
| Управление (скрыта, пока не админ) | 10 |
| Корзина | 9 |
| Меню | 4 |
| Каталог | 7 |
| Кнопка «Примерить свой принт» в скрытом блоке нанесения | 18 |
| «Уходит текст, файл надо приложить в чат» | 33 |
| Маршрут | 7 |
| Написать в Telegram | 17 |

На 1024 `.hop` нет ни у кого: текст «Свой принт» цельный, `hopCount: 0`.

Ховер только на 1440, два захода. Анимация `letter-hop`, 360ms, delay `calc(var(--d) * 25ms)`.

Кейфреймы:

```css
@keyframes letter-hop {
  0% { transform: translateY(0px); }
  42% { transform: translateY(-3px); }
  100% { transform: translateY(0px); }
}
```

Поворота в кейфреймах нет. Замер буквы «С»: пик `translateY(-3px)` / `dTop -3`, `rotate` всё время `0`. Соседние буквы отстают примерно на 25ms, от «С» до «т» 200ms. Максимальный шаг между кадрами 1.13–1.30px. Ниже базовой линии (dTop > 0) буква не уходит. Второй ховер тот же. Это короткий подскок вверх и возврат на место, без рывка одним кадром и без наклона.

## 3. «Примерить свой принт»

Видимая ссылка героя (`a.is-try.btn.btn--ghost`) на обоих экранах остаётся текстом:

- text-decoration-line: `underline`
- text-underline-offset: `4px`
- text-decoration-thickness: `auto`
- height: `16px`, padding `0`, border `0`, radius `0`
- background: `transparent`
- box-shadow: `none`
- font: `16px/16px Jost` (вес 400)
- `.hop` на ней нет

Вторая кнопка с тем же текстом (`button.btn[data-try-print]`) лежит в скрытом блоке: height `48px`, radius `0`, на 1440 заливка как у «Каталога» (rgba 0.8 + градиент), на 1024 `rgb(0,0,0)`. Пока блок закрыт, rect `0×0`.

## 4. Док

1440: `display: none`, rect `0×0`, не виден, контент не перекрывает. `main` padding-bottom `0px`.

1024: тоже `display: none`, rect `0×0`, не виден, на контент не наезжает. Ширина ровно 1024 попадает в `(min-width: 1024px)`. В шапке при этом десктопный набор: «Свой принт», корзина, меню (`display: flex`). Внизу страницы футер заканчивается у края вьюпорта (bottom 1366), дока поверх нет.

## 5. Каталог, первый ряд

12 карточек.

- 1440: 4 в первом ряду, колонки `360.127px` × 4, верх ряда y=958, высота карточки ≈ 586.
- 1024: 4 в первом ряду, колонки `256px` × 4, верх y=1377, высота ≈ 448.

## 6. Консоль

На обоих прогонах пусто: ни `console.error`, ни `pageerror`, ни упавших запросов. HTTP 200.

## Дыры, которые ещё выглядят дёшево

- «Каталог» — острый прямоугольник 48px с подписью 12px/700. На 1024 это плоский `#000` без рамки, blur и тени. На 1440 стекло в числах есть, на белом герое белая рамка 48% пропадает, остаётся чёрная плашка.
- Те же плашки: чип «Все» (32px, radius `0`, `rgb(11, 11, 11)`, тени нет), «Маршрут», «Написать в Telegram».
- `.hop` размазан по шапке и чёрным кнопкам, волна живёт не только на «Свой принт».
- Сама волна — подскок на 3px без поворота и без хода ниже строки. Возврат круче подъёма (с −3px до −0.8px примерно за 50ms).
- При доскролле к `#blanks` плашка «Каталог» стоит на y≈6 при высоте 48 и пересекает бокс логотипа. Шапка в этот момент `.is-solid`, фон `rgba(255, 255, 255, 0.91)`, высота 72px.
- На 1024 каталог всё ещё в 4 колонки по 256px. Две колонки включаются только ниже 1024.
